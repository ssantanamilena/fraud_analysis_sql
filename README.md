## fraud_analysis_sql

Análise de transações financeiras utilizando PostgreSQL para identificar padrões de fraude.  
Foram executadas queries para:

- Identificar proporção de transações fraudulentas
- Analisar valores médios de transações
- Identificar transações de alto risco
- Explorar variáveis indicativas de fraude

Dataset: Credit Card Fraud Detection.
link para download do dataset: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud/versions/3?resource=download
